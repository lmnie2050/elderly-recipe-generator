# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/c89bcfd9-5307-4998-bc53-bcb74f07f026

## Run Locally

**Prerequisites:**  Node.js

1. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key，**先複製 .env.example檔案，然後把複製的更名為.env.local，然後打開後在GEMINI_API_KEY="MY_GEMINI_API_KEY"，MY_GEMINI_API_KEY輸入你的Gemini API KEY，並且存檔，注意資安的問題**
2. Install dependencies:**先打開終端機或是VScode的終端機，然後確定在資料夾下面後輸入**
   `npm install`
3. Run the app:，**然後在終端機輸入以下，就會出現網址，點選網址就可以開始跑了**
   `npm run dev`
